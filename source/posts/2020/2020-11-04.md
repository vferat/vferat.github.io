Pycrostates is a Python library for EEG microstate analysis. I'm very proud of this project, as it was the first of mine to reach beyond my local community. It fills a real need, is now used around the world, and has more than 50 stars on GitHub.

It is also the project that helped me master continuous integration and the automation that makes a library easier to maintain. I actively maintain Pycrostates, working to improve its performance and add new features.

The code is available on [GitHub](https://github.com/vferat/pycrostates).
