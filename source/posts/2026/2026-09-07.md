# MEEG Pipelines

MEEG Pipelines is a BIDS app that automatically preprocesses MEG and anatomical images for MEG source reconstruction. It handles Maxwell filtering, T1 preprocessing with sMRIPrep, BEM model creation with additional custom methods, and the creation of source spaces and forward models. It also includes tools to build individual atlases with different software.

```{note}
This project is under construction.
```

By combining more than 10 software packages, it provides state-of-the-art, automatic MEG source-level reconstruction. It is built on Nipype and shipped with Docker and Apptainer, which makes it reproducible, and it produces a report for quality assurance.

This is the first Docker application I have developed. It comes with a Python wrapper that handles mounts, arguments and other container details, so users do not need to be familiar with container technologies. The code is available on [GitHub](https://github.com/vferat/meeg-pipelines), and more details are in the [documentation](https://vferat.github.io/meeg-pipelines/).
