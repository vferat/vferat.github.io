:::{card} Blender Brain Atlas
:link: /posts/2021/2021-11-27
:link-type: doc


```{image} https://raw.githubusercontent.com/vferat/BlenderBrainAtlas/main/static/img/preview.JPG
:align: right
:width: 200
```
BlenderBrainAtlas is a script that creates 3D objects from an MRI segmentation file (usually preprocessed with FreeSurfer). It generates a single 3D object (outer shell) for each brain region of interest in the MRI file.
+++
[https://github.com/vferat/BlenderBrainAtlas](https://github.com/vferat/BlenderBrainAtlas)
:::


:::{card} Personalized tACS Pipeline
:link: /posts/2024/2024-05-01
:link-type: doc

{modality}`eeg` {modality}`neuromod`

A pipeline that turns T1 MRI and EEG data into personalized brain stimulation parameters for the next day.
+++
[Latrèche et al., *Psychiatry Research*, 2024](https://doi.org/10.1016/j.psychres.2024.115835)
:::
